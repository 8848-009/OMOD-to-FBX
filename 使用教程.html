这是什么

这是一个把游戏模型转成通用 3D 格式的 格式转换器：

.omod / .obj 模型 → 本地转换 → .fbx 文件 → 3D 预览
  • 输入：迷你世界的 .omod、.obj 文本模型，或装着它们的 .zip 压缩包。
  • 输出：.fbx 文件；上传压缩包则返回压缩包（保留目录结构）。
  • 预览：转换后页面底部直接渲染 3D 模型，可旋转、缩放、平移、全屏。
整个工具就是一个 HTML 文件（omod2fbx.html），双击即可用浏览器打开，不依赖任何网络或软件。
2

快速开始（4 步）

  1. 打开工具：双击 omod2fbx.html，用默认浏览器打开（推荐 Chrome / Edge）。深色界面从上到下分三块：选择文件 → 转换结果 → 模型预览。
  2. 上传模型：把 .omod / .zip 直接拖进虚线框，或点击虚线框在文件选择器里选中（可按 Ctrl / Shift 多选）。
  3. 开始转换并下载：点绿色「开始转换」，转换结果区会显示解析日志和下载按钮——单个模型显示 下载 xxx.fbx，压缩包显示 下载压缩包（N 文件）。
  4. 看 3D 预览：转换成功后「模型预览」卡片自动出现，直接渲染生成物，多模型可用顶部标签切换。

支持的输入格式

格式支持情况说明
.omod✅ 直接支持迷你世界模型，主要输入格式
.obj✅ 直接支持通用文本模型，作为补充
.zip✅ 完整支持自动解压、逐个转换、打包返回，保留目录结构
.7z / .rar⚠️ 尽力而为浏览器无法原生解压，仅扫描内嵌 omod 魔数，不保证可靠
上传 .zip 时，工具只转换识别出的模型文件，其他文件（如 readme.txt、贴图）会原样保留在输出压缩包中。

典型使用场景

场景 A：转换单个模型

上传 hero.omod → 点「开始转换」→ 下载 hero.fbx → 底部直接预览。适合快速看效果。

场景 B：批量转换（ZIP 压缩包）

把多个模型打包成 models.zip（可带子目录）上传，转换后下载一个 zip，目录结构保留：

输入 models.zip              输出 models_fbx.zip
├── hero.omod          ──▶   ├── hero.fbx
├── monster.omod             ├── monster.fbx
└── readme.txt               └── readme.txt   ← 非模型文件原样保留

场景 C：转完立刻在手机上看

转换后直接在预览卡片用单指旋转、双指捏合缩放、双指拖动平移，点右上角 ⛶ 全屏查看，无需打开其他软件。

3D 预览操作

转换成功后，预览卡片自动渲染模型。顶部标签切换模型；右上角三个按钮分别是重置视角 ⟲、线框模式 ▦、全屏 ⛶。

设备旋转缩放平移
电脑（鼠标）左键拖拽滚轮右键 / Shift + 拖拽
手机 / 平板（触屏）单指滑动双指捏合双指拖动
  • 提示文字按设备自动切换（触屏显示手势说明，鼠标显示按键说明）。
  • 全屏：点右上角 ⛶；再点一次或按 Esc 退出。iPhone Safari 等不支持原生全屏的浏览器会自动用铺满屏幕的降级方案。
  • 若浏览器禁用了 WebGL（隐私模式 / 关闭硬件加速），预览区会给出提示，但转换与下载功能不受影响。

输出文件说明

文件格式说明
.fbxFBX 7.4 ASCII主输出，可直接导入主流 3D 软件
.objWavefront OBJ兜底几何体（勾选后生成）
.mtlMaterial TemplateOBJ 的材质描述（勾选后生成）
关于贴图：.mtl 只是材质参数描述，原始 .png / .jpg 贴图纹理不会嵌入或单独导出。需要贴图请自行准备并把路径对应到材质上。

导入到 3D 软件

Blender

文件(File) → 导入(Import) → FBX → 选择文件。若显示空白，可勾选"导出 OBJ"改用 OBJ 导入；Blender 默认 Z 轴向上，方向不对时在导入选项调整 Up Axis。

Maya / 3ds Max

File → Import → 选择 .fbx，用默认设置即可。骨骼模型可在 Outliner / 层级面板查看骨骼结构。

在线预览网站

直接把 .fbx 拖入支持 FBX 的网站（多基于 Three.js FBXLoader）。本工具的输出已针对该解析器做过兼容性修复，可正常打开。

常见问题 FAQ

页面打不开 / 双击没反应？
换用 Chrome / Edge；确认文件是完整的单个 .html，没被下载工具截断。
转换后导入软件看不到模型？
确认源 .omod 有效；勾选"同时导出 OBJ + MTL"，用 OBJ 导入对比。若 OBJ 正常而 FBX 异常，是目标软件的 FBX 兼容问题。
模型错乱 / "人不人鬼不鬼"？
这通常是顶点布局解析错误。本工具内置顶点布局自动检测（适配 stride 8 / 10 / 12 等多种 omod 变体），已用多个真实武器模型对照正确 FBX 逐顶点验证做到零误差。如仍遇到错乱，请把该 .omod 反馈给作者。
动画没有动起来？
动画解析是实验性功能，需勾选"导出动画关键帧"，且取决于源模型是否含可识别动画轨迹；很多 omod 本身只有静态绑定姿态。
上传 .7z / .rar 没反应？
浏览器无法原生解压这两种格式，工具只能扫描内嵌 omod 魔数（不可靠）。请先用系统压缩工具解压，再用 .zip 重新打包上传。
文件会不会被上传？
不会。所有解析、转换、预览都在浏览器本地内存完成，页面没有任何向服务器发送文件的逻辑，可完全离线使用。
支持 macOS / 手机吗？
能运行现代浏览器的系统都支持。手机端已针对触摸旋转、双指缩放、全屏做了适配；大批量转换在桌面端体验更好。

注意事项与限制

  1. 压缩包优先用 ZIP：.7z / .rar 只做魔数扫描兜底，不可靠。
  2. 贴图不导出：仅生成几何体与材质参数，不含图片纹理。
  3. 动画为实验性：不保证所有模型的动画都能正确还原。
  4. 大文件性能：超大压缩包或超多模型可能让浏览器短暂卡住，建议分批转换。
  5. FBX 版本：输出 FBX 7.4 ASCII；极老的只认 6.x 二进制的软件可能不兼容，可改用 OBJ。
  6. WebGL：3D 预览依赖浏览器 WebGL；预览不可用不影响转换和下载。

技术信息

  • 形态：单个 HTML，内嵌纯 JS 转换引擎（由 omod转fbx-v1.1.py 移植）、fflate（ZIP 处理）、Three.js（3D 预览）。
  • 解析：用 DataView 读 omod 二进制——顶点 / UV / 法线 / 索引、材质、骨骼层级、动画轨迹。
  • 顶点布局自动检测：根据「顶点数据块长度 = 顶点数 × stride」反推每种 omod 的 stride（8 / 10 / 12）与起始偏移，UV 的 V 分量自动翻转；已对多个真实模型与正确 FBX 逐顶点验证零误差。
  • 输出：FBX 7.4 ASCII，标准 tab 缩进、多行节点、a: 数组属性、正确的父子连接方向（已针对 Three.js FBXLoader / Blender / Maya 兼容性实测修复）。
  • 隐私：无外部网络依赖，双击即用，文件不上传。
