# OMOD → FBX 转换器

**一个单文件、纯浏览器、离线可用的迷你世界 `.omod` 模型转换工具。**

把 `.omod` 模型（或装着它的压缩包）拖进网页，即可在本地转换成通用的 `.fbx` 文件，并在转换后直接进行 3D 预览。文件全程不上传服务器，无需安装任何软件或依赖。

## 特性

- **单文件、零依赖**：整个工具就是一个 `omod2fbx.html`，双击用浏览器打开即用。
- **完全离线、隐私安全**：所有解析与转换都在浏览器本地内存完成，**文件不上传**，可断网使用。
- **批量转换**：支持上传 `.zip` 压缩包，自动解压、逐个转换并保留目录结构打包返回。
- **转换即预览**：内置 Three.js 3D 预览，支持鼠标 / 触屏旋转、缩放、平移，以及全屏查看。
- **顶点布局自动检测**：自动适配多种 omod 变体（每顶点 stride 8 / 10 / 12），UV 的 V 分量自动翻转，已用多个真实武器模型对照正确 FBX **逐顶点零误差**验证。
- **兼容性修复**：输出的 FBX 针对 Three.js FBXLoader / Blender / Maya 做过标准兼容性修复，在线预览网站可直接打开。
- **可选能力**：额外导出 OBJ + MTL 兜底文件；实验性导出骨骼动画关键帧。
- **深色界面、移动端适配**：触屏手势、全屏降级，手机也能用。

## 快速开始

1. 下载本仓库的 `omod2fbx.html`（**一个文件即可**，其余文档可选）。
2. 用 Chrome / Edge 等现代浏览器双击打开。
3. 把 `.omod` 模型或 `.zip` 压缩包拖进页面 → 点 **「开始转换」**。
4. 下载生成的 `.fbx`（或压缩包）；页面底部会直接渲染 3D 预览。

> 想看图文教程？见 [使用教程 HTML](./omod2fbx-使用教程.html) 或 [使用教程 Markdown](./omod2fbx-使用教程.md)。

## 支持的文件格式

| 输入 | 支持情况 | 说明 |
|---|---|---|
| `.omod` | ✅ | 迷你世界模型，主要输入 |
| `.obj` | ✅ | 通用文本模型 |
| `.zip` | ✅ | 完整支持，保留目录结构打包返回 |
| `.7z` / `.rar` | ⚠️ | 浏览器无法原生解压，仅做内嵌 omod 魔数扫描，建议改用 `.zip` |

**输出**：`.fbx`（FBX 7.4 ASCII）；勾选后可额外得到 `.obj` + `.mtl`。

## 3D 预览操作

| 设备 | 旋转 | 缩放 | 平移 | 全屏 |
|---|---|---|---|---|
| 鼠标 | 左键拖拽 | 滚轮 | 右键 / Shift + 拖拽 | 右上角 ⛶ |
| 触屏 | 单指滑动 | 双指捏合 | 双指拖动 | 右上角 ⛶ |

预览依赖浏览器 WebGL；WebGL 不可用时转换与下载仍正常。

---

## 限制

- 动画解析为实验性功能，不保证所有模型正确还原。
- 超大压缩包建议分批转换，避免浏览器卡顿。
- 极老的只认 FBX 6.x 二进制的软件可能不兼容，可改用 OBJ 兜底。
